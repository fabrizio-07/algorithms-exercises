# Array recursion

### How to compile
Use the command:

```bash
g++ <file.cpp> [-o executable_name]
```

to generate the executable file.

### How to execute executable file
There are two ways to execute it:

```bash
./<executable_file>
```

or passing arguments to the program:

```bash
./<executable_file> [argv1] [argv2] ... [argvn]
```

## `argv`s:

`argv`s depends on what the program does. Follows a list of what they mean in each `.cpp` file:

-  *countNegatives.cpp*: it allows `n` `int` arguments, which are the values of the array in which to count the number of negative values.
- *evenMultiply.cpp*: it allows `n` `int` arguments, which are the values of the array whose even values are to be multiplied.
- *countNumAboveMean.cpp*: it allows `n` `int` arguments, which are the values of the array in which to count the number of elements above the arithmetic mean.
- *evenOddDifference.cpp*: it allows `n` `int` arguments, which are the values of the array whose odd elements are subtracted to the even ones. 
- *checkSymmetry.cpp*: it allows `n` `int` arguments, which are the values of the array which is checked for its symmetry.
- *countLocalPeaks.cpp*: it allows `n` `int` arguments, which are the values of the array in which to count the number of local peaks.
- *getMean.cpp*: it allows `n` `int` arguments, which are the values of the array whose is calculated the arithmetic mean.
- *checkIncreasingSequence.cpp*: it allows `n` `int` arguments, which are the values of the array which is checked if is there any increasing subsequence in it.
- *countUniqueValues.cpp*: it allows `n` `int` arguments, which are the values of the array in which to count the number of unique elements.
- *alternateMultiply.cpp*: it allows `n` `int` arguments, which are the values of the array in which to calculate the alternating multiplication.
